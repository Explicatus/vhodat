# 🏠 Входът — SaaS за управление на етажна собственост

Платформа за домоуправители, управителни съвети и фирми за професионално управление на сгради в България.

## Функционалност
| Модул | Управител | Собственик / обитател |
|---|---|---|
| **Обекти** | Апартаменти, магазини, гаражи; ид. части, живущи, такса; масов импорт от Excel; разпределяне на таксата по живущи / ид. части | — |
| **Такси и плащания** | Начисляване на месечни такси и фонд „Ремонт“ (без дублиране), еднократни вноски, плащания, разписки, CSV експорт | Собствено салдо, история, IBAN за плащане, разписки |
| **Разходи** | Въвеждане по категории | Пълна прозрачност — вижда всички разходи |
| **Обяви** | Публикуване, закачане | Четене |
| **Гласувания** | Създаване, приключване, кой как гласува | Гласуване (1 глас на обект, тежест по ид. части) |
| **Сигнали** | Смяна на статус | Подаване на сигнали |
| **Настройки** | Данни на ЕС, код за покана, роли, свързване на потребител с обект | — |

Един акаунт може да управлява **много сгради** (превключвател в менюто).

## Стек
Next.js 15 (App Router, Server Actions) · TypeScript · Prisma · SQLite (dev) / PostgreSQL (prod) · Tailwind CSS · JWT сесии в httpOnly cookie

## Стартиране
```bash
npm install
cp .env.example .env
npx prisma db push
npm run db:seed      # демо данни
npm run dev          # http://localhost:3000
```
Демо акаунти: `manager@demo.bg` / `demo1234` (управител), `resident@demo.bg` / `demo1234` (собственик, ап. 2). Код за покана: `DEMO2026`.

## Продукция
1. В `prisma/schema.prisma` сменете `provider = "postgresql"` и задайте `DATABASE_URL` (напр. Neon, Supabase, Railway).
2. Задайте дълъг случаен `SESSION_SECRET`.
3. Деплой на Vercel / Railway / Docker: `npm run build && npm start`.
